# Portfolio Domain Model

The domain model for Ali Ahmed's software engineering portfolio website, governing showcase projects, technical categorisation, and deployment links.

## Language

**Project**:
A curated showcase record representing a production-grade application engineered by Ali Ahmed, containing architectural problems, solutions, tech stacks, and source links.
_Avoid_: Case study, portfolio item, repo

**Featured Project**:
The premier showcase application positioned at the root of the project index, rendered in a 2×2 dual-span hero card within the editorial grid.
_Avoid_: Highlighted project, hero item, spotlight

**Live Demo**:
A publicly accessible, cloud-hosted deployment (Vercel, Firebase Web App) allowing visitors to test or interact with the software directly in the browser.
_Avoid_: Preview URL, web link, sandbox link

**Category**:
The strict architectural classification assigned to a project, limited to mobile, web, or fullstack.
_Avoid_: Platform, domain, type

**Accent Token**:
The signature HEX color associated with an individual project used for ambient glow, tags, and visual differentiation.
_Avoid_: Theme color, brand color
